SLIDE 4 - PROBLEMA E SOLUCAO
================================================================================

  Titulo: Por que o Smart Secagem?

  PROBLEMA:
  - Perdas pos-colheita de 10-30% da producao
  - Falta de monitoramento em tempo real
  - decisoes manuais baseadas em intuicao
  - Risco de incendio em secadores
  - Dificuldade de otimizar processos

  SOLUCAO:
  - Monitoramento IoT em tempo real
  - IA para analise preditiva
  - Automacao de processos
  - Alertas inteligentes
  - Relatorios automaticos

SLIDE 10 - SISTEMA DE PREVISAO DE RISCO DE FOGO
================================================================================

  Titulo: Prevencao de Incendio em Secadores

  O que monitora:
  - Temperatura de rolamentos (mancal)
  - Nivel de gas CO (abafamento)
  - Vibracao
  - Taxa de elevacao termica

  5 Niveis de Risco:
  ┌─────────────────────────────────────────────────┐
  │  SEGURO     (verde)   │  Score = 0             │
  │  ATENCAO    (azul)    │  Score >= 1            │
  │  AVISO      (amarelo) │  Score >= 3            │
  │  CRITICO    (laranja) │  Score >= 5            │
  │  EMERGENCIA (vermelho)│  Score >= 7            │
  └─────────────────────────────────────────────────┘

  Acoes:
  - Alertas em tempo real
  - Dialogo de emergencia
  - Recomendacoes automaticas

SLIDE 11 - EQUILIBRIO HIGROSCOPICO E DELTA T
================================================================================

  Titulo: Inteligencia de Aeracao

  Conceito:
  - Analise se ar externo pode remover umidade do grao
  - Calculo de Delta T (diferenca de temperatura)
  - Protecao contra sobre-secagem

  Metricas Monitoradas:
  ┌──────────────────┬────────────┬──────────────────────────┐
  │ Metrica          │ Criticidade│ Descricao                │
  ├──────────────────┼────────────┼──────────────────────────┤
  │ Temp. Interna    │ Alta       │ Detecta pontos quentes   │
  │ Umidade Relativa │ Alta       │ Ponto de equilibrio      │
  │ Ponto de Orvalho │ Media      │ Previne condensacao      │
  │ Delta T          │ Operac.    │ Resfriamento efetivo     │
  └──────────────────┴────────────┴──────────────────────────┘

  Decisao Inteligente:
  - Aeracao ATIVA apenas quando Delta T favoravel
  - Auto-desligamento em condicoes criticas

SLIDE 14 - ARQUITETURA DE INTEGRACAO
================================================================================

  Titulo: Fluxo de Dados Completo

  [Diagrama de fluxo]

  USUARIO → Flutter App
       │
       ├──→ GET /contexto/ → Django API (8000)
       │         │
       │         └──→ Dados operacionais
       │
       └──→ POST /chat-stream/ → AI Microservice (8001)
                 │
                 ├──→ prompt + context + history
                 │
                 └──→ SSE Stream → Resposta IA

  TIPOS DE EVENTO SSE:
  - message: conteudo da resposta
  - thought: raciocinio da IA (chain-of-thought)
  - metrics: metricas de performance
  - error: erros
  - done: conclusao
