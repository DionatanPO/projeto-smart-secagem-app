# Module: Unidade Armazenadora Management

## Purpose
Management of storage units (U.A.), including registration and configuration of storage facilities.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - UnidadeArmazenadoraManagementController extends GetxController
- `views/` - UI screens

## Key Files
- `views/unidade_armazenadora_management_view.dart` - Main view
- `controllers/unidade_armazenadora_management_controller.dart` - Main controller
