# Module: Batch Management

## Purpose
Management of grain batches stored in silos, tracking batch details and history.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - BatchManagementController extends GetxController
- `views/` - UI screens

## Key Files
- `views/batch_management_view.dart` - Main view
- `controllers/batch_management_controller.dart` - Main controller

## Route
`/batch-management` (protected)
