# Module: Smart Sense IA

## Purpose
AI-powered predictive analytics panel: 48h hotspot prediction, hygroscopic equilibrium, delta T metrics, dew point analysis, and energy optimization engine.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - SmartSenseIAController extends GetxController
- `views/` - UI screens

## Key Files
- `views/smart_sense_ia_view.dart` - Main AI dashboard
- `controllers/smart_sense_ia_controller.dart` - Main controller

## Route
`/smart-sense-ia` (protected)
