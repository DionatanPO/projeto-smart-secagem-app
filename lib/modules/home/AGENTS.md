# Module: Home

## Purpose
Painel Dashboard with sidebar and internal routing for the authenticated area.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - HomeController extends GetxController
- `views/` - UI screens

## Key Files
- `views/home_view.dart` - Main home view
- `controllers/home_controller.dart` - Main controller

## Route
`/home` (protected)
