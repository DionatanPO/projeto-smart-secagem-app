# Module: Secagem (Drying)

## Purpose
Drying process control and monitoring. Manages dryer parameters, thermal metrics, and process optimization.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - SecagemController extends GetxController
- `views/` - UI screens

## Key Files
- `views/secagem_view.dart` - Main drying overview
- `views/secador_detalhes_view.dart` - Dryer details screen
- `controllers/secagem_controller.dart` - Main controller

## Route
`/secagem` (protected)
