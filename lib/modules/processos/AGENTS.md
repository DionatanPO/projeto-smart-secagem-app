# Module: Processos (Processes)

## Purpose
Management and tracking of drying processes, including active process monitoring and history.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - ProcessosController extends GetxController
- `views/` - UI screens

## Key Files
- `views/processos_view.dart` - Main view
- `controllers/processos_controller.dart` - Main controller

## Route
`/processos` (protected)
