# Module: Login

## Purpose
Authentication screen with premium UI/UX validations. Entry point for authenticated area access.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - LoginController extends GetxController
- `views/` - UI screens

## Key Files
- `views/login_view.dart` - Main login view
- `controllers/login_controller.dart` - Main controller

## Route
`/login` (public)
