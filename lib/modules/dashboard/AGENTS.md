# Module: Dashboard

## Purpose
Central restricted-area dashboard with unified navigation, metrics overview, and charts. Container for accessing all other protected modules via a sidebar drawer.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - DashboardController extends GetxController
- `views/` - UI screens

## Key Files
- `views/dashboard_view.dart` - Main dashboard view
- `controllers/dashboard_controller.dart` - Main controller
