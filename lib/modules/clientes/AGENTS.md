# Module: Clientes (Clients)

## Purpose
Client/customer registration and management for agricultural producers.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - ClientesController extends GetxController
- `views/` - UI screens

## Key Files
- `views/clientes_view.dart` - Main view
- `controllers/clientes_controller.dart` - Main controller

## Route
`/clientes` (protected)
