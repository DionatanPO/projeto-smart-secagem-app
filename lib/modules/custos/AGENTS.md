# Module: Custos (Costs)

## Purpose
Cost tracking and financial management for drying and storage operations.

## Structure
- `bindings/` - GetX dependency injection
- `controllers/` - CustosController extends GetxController
- `views/` - UI screens

## Key Files
- `views/custos_view.dart` - Main view
- `controllers/custos_controller.dart` - Main controller

## Route
`/custos` (protected)
