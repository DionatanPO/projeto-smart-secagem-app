================================================================================
                          1. VISAO GERAL DO PROJETO
================================================================================

O Smart Secagem e uma plataforma completa de monitoramento e automacao para
a operacao pos-colheita de graos. O sistema integra gestao de silos, controle
de secagem, monitoramento de dispositivos IoT e analises preditivas via
Inteligencia Artificial para otimizar o armazenamento e a qualidade dos graos.

ARQUITETURA TECNICA:
--------------------
  Frontend:      Flutter (Web, Mobile, Desktop)
  Backend:       Django REST API (porta 8000)
  AI Service:    Microservice de IA (porta 8001)
  Estado:        GetX (State Management + Routing)
  Storage:       GetStorage (cache) + FlutterSecureStorage (tokens)
  HTTP Client:   Dio (API principal) + http (SSE streaming IA)
  Graficos:      fl_chart
  Code Gen:      freezed + json_serializable + build_runner

┌─────────────────────────────────────────────────────────────────────────────┐
│              3.1 DASHBOARD IA - RESUMO OPERACIONAL                          │
├─────────────────────────────────────────────────────────────────────────────┤

  Localizacao: lib/modules/dashboard/

  O Dashboard IA e o coracao analitico do sistema. Ele recebe dados
  operacionais em tempo real e gera resumos inteligentes via LLM.

  FLUXO OPERACIONAL:
  -------------------
  1. fetchContext() busca dados operacionais via GET /contexto/
  2. Contexto e envolto em tags XML <contexto_operacional>
  3. Prompt e enviado via POST /chat-stream/ (SSE streaming)
  4. Resposta e exibida incrementalmente como Markdown

  5 TIPOS DE RELATORIO PRE-DEFINIDOS:
  ------------------------------------
  a) Relatorio Executivo 24h
     - Panorama operacional das ultimas 24 horas
     - Alertas ativos e recomendacoes prioritarias

  b) Relatorio de Custos de Secagem
     - Analise financeira por processo e secador
     - Custo por tonelada e projecoes

  c) Relatorio de Saude dos Lotes
     - Analise de risco e qualidade dos lotes
     - Tempo de armazenamento e condicoes

  d) Relatorio de Ocupacao e Capacidade
     - Taxa de ocupacao dos silos
     - Tendencias e projecao de saturacao

  e) Relatorio de Gargalos Operacionais
     - Diagnostico de gargalos na cadeia:
       RECEPCAO -> SECAGEM -> ARMAZENAMENTO -> EXPEDICAO

  RECURSOS TECNICOS:
  -------------------
  - Streaming de resposta token por token
  - Tratamento de eventos "thought" (chain-of-thought)
  - Tratamento de eventos "metrics"
  - Tracking de tempo de resposta
  - Exportacao para PDF via PdfService
  - Persistencia de prompt via GetStorage

┌─────────────────────────────────────────────────────────────────────────────┐
│              3.3 SISTEMA DE PREVISAO DE RISCO DE FOGO                       │
├─────────────────────────────────────────────────────────────────────────────┤

  Localizacao: lib/core/models/fire_risk_model.dart
               lib/modules/secagem/widgets/fire_risk_panel.dart

  Sistema client-side baseado em regras para avaliacao de risco
  de incendio em secadores. NAO usa ML - e baseado em thresholds
  e scoring multi-fator.

  ALGORITMO DE SCORING:
  ----------------------
  Fatores avaliados:
    - Temperatura do sensor
    - Nivel de gas (CO)
    - Vibracao
    - Taxa de elevacao termica (C/min)

  Niveis de Risco por Tipo de Sensor:
  ------------------------------------
  SENSOR MANCAL (Rolamento):
    - Aviso:     >= 75C
    - Critico:   >= 90C
    - Emergencia:>= 110C

  SENSOR ABAFAMENTO (CO):
    - Aviso:     >= 50ppm
    - Critico:   >= 150ppm
    - Emergencia:>= 400ppm

  ESCORE FINAL (0-12+):
  -----------------------
  Score >= 7  →  EMERGENCIA (vermelho)
  Score >= 5  →  CRITICO (laranja)
  Score >= 3  →  AVISO (amarelo)
  Score >= 1  →  ATENCAO (azul)
  Score = 0   →  SEGURO (verde)

  RECURSOS:
  ----------
  - Monitoramento em tempo real de todos os sensores
  - Agregacao de nivel de fogo geral por secador
  - Dialogo de emergencia com feedback haptico
  - Cards de risco detalhados com dados de telemetria
  - Dialogo educativo explicando tipos de sensor e niveis

┌─────────────────────────────────────────────────────────────────────────────┐
│              3.4 EQUILIBRIO HIGROSCOPICO E DELTA T                          │
├─────────────────────────────────────────────────────────────────────────────┤

  Localizacao: lib/modules/support/controllers/support_controller.dart

  Sistema de decisao inteligente para aeracao de graos baseado em
  analise de equilibrio higroscopico.

  FLUXO DE DECISAO:
  ------------------
  1. Monitoramento Constante
     - Leitura de sensores a cada 60 segundos
     - Coleta de temperatura e umidade interna/externa

  2. Analise de Equilibrio Higroscopico
     - Calculo se o ar externo pode remover umidade do grao
     - Verificacao de nao sobre-secagem

  3. Decisao Inteligente
     - Aeracao ativa APENAS se Delta T e favoravel
     - Umidade relativa externa na janela ideal

  4. Protecao de Qualidade
     - Auto-desligamento se detecta tendencia de aquecimento
     - Protecao contra aumento de umidade na massa de graos

  METRICAS MONITORADAS:
  ----------------------
  Atributo              | Criticidade | Descricao
  ----------------------|-------------|----------------------------------
  Temperatura Interna   | Alta        | Detecta pontos quentes e
                        |             | atividade biologica
  Umidade Relativa      | Alta        | Define ponto de equilibrio
                        |             | para evitar ganho de peso
  Ponto de Orvalho      | Media       | Previne condensacao nas
                        |             | paredes frias do silo
  Delta T               | Operacional | Diferenca entre ar externo e
                        |             | massa de grao para resfriamento
