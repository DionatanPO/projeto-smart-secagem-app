SLIDE 3 - VISAO GERAL DO PROJETO
================================================================================

Smart Secagem e uma plataforma completa de monitoramento e automacao
para operacoes pos-colheita de graos.

Destaques:
- Flutter (Web, Mobile, Desktop)
- Monitoramento IoT em tempo real
- IA integrada para analise preditiva
- 19 modulos especializados
- Backend Django + AI Microservice


================================================================================
SLIDE 4 - PROBLEMA E SOLUCAO
================================================================================

PROBLEMA:
- Perdas pos-colheita de 10-30% da producao
- Falta de monitoramento em tempo real
- Decisoes manuais baseadas em intuicao
- Risco de incendio em secadores

SOLUCAO:
- Monitoramento IoT em tempo real
- IA para analise preditiva
- Automacao de processos
- Alertas inteligentes
- Relatorios automaticos


================================================================================
SLIDE 5 - STACK TECNOLOGICA
================================================================================

FRONTEND: Flutter (Dart 3.x) + GetX
BACKEND: Django REST API (porta 8000)
IA: AI Microservice (porta 8001)
IOT: Sensores (temp, mancal, CO) + Motores
GRAFICOS: fl_chart
ARMazenAMENTO: GetStorage + FlutterSecureStorage


================================================================================
SLIDE 6 - ARQUITETURA TECNICA
================================================================================

FLUTTER CLIENT
      │
      ├──→ Django REST API (8000) → Dados, CRUD, Auth
      │
      └──→ AI Microservice (8001) → LLM, Streaming, IA

Comunicacao via SSE (Server-Sent Events) para streaming de IA

================================================================================
SLIDE 9 - SMART SENSE IA
================================================================================

Chat conversacional para consultas em linguagem natural.

Como funciona:
1. Usuario faz pergunta
2. Sistema busca contexto operacional
3. Contexto + pergunta enviados a IA
4. Resposta streaming em tempo real

Capacidades: Sensores, lotes, silos, processos


================================================================================
SLIDE 10 - RISCO DE FOGO
================================================================================

Sistema client-side de prevencao de incendio em secadores.

SENSORES: Mancal (temp), Abafamento (CO), Vibracao

5 NIVEIS DE RISCO:
- Seguro (verde)
- Atenucao (azul)
- Aviso (amarelo)
- Critico (laranja)
- Emergencia (vermelho)

Scoring: 0 a 12+ pontos


================================================================================
SLIDE 11 - EQUILIBRIO HIGROSCOPICO
================================================================================

Decisao inteligente de aeracao baseada em:

- Temperatura Interna: detecta pontos quentes
- Umidade Relativa: ponto de equilibrio
- Ponto de Orvalho: previne condensacao
- Delta T: resfriamento efetivo

Aeracao ativa APENAS quando Delta T favoravel
